# 🎵 가사 다양성 개선 완료!

## 😱 발견된 문제

**증상**: 15곡을 생성했을 때 **가사가 거의 똑같이** 나옴
```
곡 1: "홈카페이 지나가"
곡 2: "등산이 지나가"  
곡 3: "커피이 떠올라"
...
```

→ **단어만 바뀌고 구조/문장이 동일**

---

## 🔍 원인 분석

1. **LLM이 비슷한 패턴으로 응답**
   - 같은 프롬프트 → 같은 구조의 가사
   - 템플릿 기반 생성의 한계

2. **다양성 지시 부족**
   - "독창적으로" 만으로는 부족
   - 구체적인 가이드라인 필요

3. **랜덤 요소 없음**
   - 매번 같은 접근 방식
   - 시점/시간/장소/감정 고정

---

## ✅ 해결 방법

### 1️⃣ Temperature 상승
```javascript
temperature: 1.2  // 기본 1.0 → 1.2로 증가 (더 창의적)
```

```javascript
시스템 프롬프트:

```

### 3️⃣ getRandomApproach() 함수 추가

**15가지 시점**:
- 1인칭 시점 - '나'의 직접적인 경험
- 2인칭 시점 - '너'를 향한 메시지
- 3인칭 관찰자 - 밖에서 바라보는 시선
- 과거 회상 - 지나간 시간 돌아보기
- 현재 진행형 - 지금 이 순간 포착
- 미래 전망 - 앞으로의 희망
- 대화체 - 대화하듯 자연스럽게
- 독백 - 내면의 깊은 생각
- 질문형 - 질문으로 구성
- 서술형 - 이야기를 들려주듯
- 감각 중심 - 오감을 극대화
- 대비 구조 - 상반된 상황 대조
- 순환 구조 - 처음과 끝이 연결
- 비유/은유 - 추상적 표현 활용
- 구체적 장면 - 영화처럼 디테일

**7가지 시간대**:
- 새벽 4시의 고요한 순간
- 아침 햇살이 들어오는 시간
- 점심시간의 분주한 풍경
- 오후 황혼의 따뜻한 빛
- 저녁 노을이 지는 순간
- 밤의 고요와 별빛
- 자정을 넘긴 깊은 밤

**10가지 장소**:
- 작은 카페 창가 자리
- 붐비는 지하철 안
- 한적한 공원 벤치
- 높은 빌딩 옥상
- 조용한 도서관 한구석
- 바다가 보이는 해변
- 산 정상의 전망대
- 골목길 작은 가게
- 집 안 아늑한 방
- 거리의 버스 정류장

**10가지 핵심 감정**:
- 그리움과 향수
- 희망과 설렘
- 평온과 안정
- 불안과 초조함
- 슬픔과 외로움
- 기쁨과 감사
- 분노와 좌절
- 혼란과 갈등
- 해방감과 자유
- 사랑과 그리움
