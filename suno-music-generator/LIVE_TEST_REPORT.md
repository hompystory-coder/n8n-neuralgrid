## 🐛 발견된 문제점

### 1. Gemini API MAX_TOKENS 경고 ⚠️
**증상**: 
- 일부 가사 생성에서 `finishReason: MAX_TOKENS` 발생
- LLM 응답이 잘려서 불완전한 가사 생성 (시도 1/3에서 실패, 재시도로 해결)

**영향**: 
- 경미함 - 재시도 로직으로 모두 해결됨
- 최종적으로 모든 곡이 완전한 가사로 생성됨

**해결 방안**:
- ✅ 이미 3회 재시도 로직 구현됨
- 추가 개선: `maxTokens` 증가 (3072 → 4096) 고려

### 2. YouTube 메타데이터 LLM 제목 생성 실패 ⚠️
**증상**: 
- YouTube 플레이리스트 제목 생성에서 LLM 응답 파싱 실패
- 폴백 템플릿 사용: "듣기 좋은 pop 플레이리스트 🎵 work · 15곡"

**영향**: 
- 중간 - YouTube 메타데이터 품질 저하
- 음악 생성 자체에는 영향 없음

**근본 원인**: 
- Gemini API 응답 잘림 (`finishReason: MAX_TOKENS`)
- YouTube 제목 생성 시스템 프롬프트가 너무 길어서 응답이 잘림

**해결 방안**:
- systemPrompt 간소화
- maxTokens 증가
- 응답 형식 최적화 (더 짧은 JSON 구조)
