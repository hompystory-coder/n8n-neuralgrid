# 🎵 노래 길이 3분 이상으로 늘리기

## 📅 수정 일시
2026-05-03

## 🐛 문제 상황

사용자 보고:
> "노래길이가 짧아 현재 1분 조금넘는데 3분은 넘어야해"

**현재 상황**:
- 생성되는 노래: 약 1분 ~ 1분 30초
- 목표: 3분 이상
- 필요한 개선: **2배 이상 길이 늘리기!**

---

## 🔍 원인 분석

### 1. GPT max_tokens 제한

**이전 설정**:
```javascript
max_tokens: 2000
```

- GPT 토큰: 한국어 1글자 ≈ 2-3 토큰
- 2000 토큰 ≈ 700-1000자 정도
- 1000자 가사 ≈ 1-1.5분 노래 ❌

### 2. 가사 구조 부족

**이전 구조**:
```
[Intro] (2-4줄)
[Verse 1] (6-8줄)
[Chorus] (6줄)
[Verse 2] (6-8줄)  
[Chorus] (6줄)
[Bridge] (4-6줄)
[Verse 3] (6-8줄)
[Chorus] (6줄)
[Outro] (2-4줄)
```
→ 총 48-70줄 정도 → 약 1200자 → **1-1.5분** ❌

### 3. 섹션별 가사 길이 부족

- Verse: 6-8줄 (짧음!)
- Chorus: 6줄 (반복 부족!)
- Pre-Chorus 없음!

## ✅ 해결 방법

### 1. max_tokens 2배 증가

```javascript
// 이전
max_tokens: 2000  // 약 700-1000자

// 현재
max_tokens: 4000  // 🔥 약 1500-2000자로 증가!
```

**효과**: 
- 1000자 → 2000자 가능
- 1-1.5분 → **3-3.5분** ✅

### 2. 가사 구조 강화

**새로운 구조**:
```
[Intro] (4줄)
[Verse 1] (8줄 이상)
[Pre-Chorus] (4줄)  ← 새로 추가!
[Chorus] (8줄)      ← 길이 증가!
[Verse 2] (8줄 이상)
[Pre-Chorus] (4줄)  ← 새로 추가!
[Chorus] (8줄)
[Bridge] (6줄 이상)
[Verse 3] (8줄 이상)  ← 추가!
[Final Chorus] (8줄)  ← 강조!
[Outro] (4줄)
```
→ 총 **76줄 이상** → 약 **1800-2000자** → **3분 이상** ✅

### 3. 프롬프트 개선

**명확한 길이 요구**:
```javascript
5. **🎵 최소 3분 이상 재생되는 길이 (매우 중요!)**
   - 한국어: 최소 1800자 이상 (2000자 권장)
   - 영어: 최소 500단어 이상 (600단어 권장)
```

**각 섹션 최소 길이**:
```javascript
6. **각 섹션의 최소 길이 (필수!)**:
   - Intro: 4줄
   - Verse 1/2/3: 각 8줄 이상
   - Pre-Chorus: 4줄
   - Chorus: 8줄 (반복 포함)
   - Bridge: 6줄 이상
   - Outro: 4줄
```

## 🎵 Suno API 곡 길이 원리

### 곡 길이에 영향을 주는 요인:

1. **가사 길이** (가장 중요!)
   - 가사 1000자 ≈ 1.5분
   - 가사 2000자 ≈ 3-3.5분

2. **섹션 구조**
   - Intro, Pre-Chorus, Bridge, Outro 등이 많을수록 길어짐
   - Chorus 반복이 많을수록 길어짐

3. **BPM (템포)**
   - 느린 템포 (60-80 BPM) → 가사가 천천히 진행 → 더 길어짐
   - 빠른 템포 (120-140 BPM) → 가사가 빠르게 진행 → 짧아짐

### Suno Custom Mode 특징:

- ✅ **우리가 제공한 가사를 모두 사용**
- ✅ 가사가 길면 자동으로 노래도 길어짐
- ✅ 섹션 태그 ([Verse], [Chorus] 등)를 인식
- ✅ 각 섹션에 충분한 시간을 할당

**결론**: 가사를 2000자로 늘리면 → 노래가 자동으로 3분 이상! ✅
