# 🎵 가사 길이 최적화 최종 보고서

## 📊 사용자 피드백 및 개선사항

### 🔴 문제점 (사용자 피드백)
1. **가사가 너무 길다** (800-900자)
2. **작곡에 맞지 않는 구조**
3. **불필요하게 복잡한 가사**

### ✅ 해결 방안

#### 1. 프롬프트 대폭 간소화
**Before (500+ 줄)**:
- 긴 설명, 예시, 체크리스트
- 복잡한 요구사항
- 혼란스러운 지시사항

**After (30줄)**:
```
**이슈**: ${issue.title}
**분위기**: ${issue.mood}
**키워드**: ${issue.keywords}

**요구사항**:
1. 이슈를 직접 언급하지 말고 감정으로 표현
2. 강렬한 감정 / 재미있는 이야기 / 서정적 분위기 중 선택
3. **총 길이: 350-550자** (반드시 준수!)
4. 구조: [Intro] → [Verse 1] → [Chorus] → [Verse 2] → [Chorus] → [Bridge] → [Outro]
```

#### 2. 명확한 길이 제한
- **한국어**: 350-550자 (최대 700자)
- **영어**: 120-250단어 (최대 280단어)
- Gemini에게 직접 "X자 이내"로 명시

#### 3. 스마트 자르기 로직
```javascript
if (가사 길이 > 550자) {
  // Outro 섹션을 유지하면서 중간 부분 축소
  // 완결성 있는 가사 구조 보장
}
```

#### 4. 파라미터 최적화
- **temperature**: 1.0 → 0.9 (더 일관된 길이)
- **maxTokens**: 2048 → 1200 (더 짧은 응답)
