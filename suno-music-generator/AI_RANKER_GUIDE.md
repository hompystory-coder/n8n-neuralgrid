# 🤖 AI 음악 순위 자동 추천 시스템

## 📋 개요

Gemini AI를 활용하여 생성된 음악들을 자동으로 분석하고, **유튜브 시청 지속률**을 최적화할 수 있는 최적의 트랙 순서를 추천하는 시스템입니다.

---

## 🎯 핵심 기능

### 1. AI 기반 음악 분석
- **첫 30초 매력도** (50점): 인트로 후킹, 즉각적인 흥미 유발
- **감정 몰입도** (30점): 공감 가능한 감정, 스토리텔링
- **중독성** (20점): 반복 청취 욕구, 기억에 남는 후렴구

### 2. 3가지 배치 전략

#### 🎣 후킹 우선 배치 (권장)
- **설명**: 최고 점수 곡을 첫 트랙에 배치
- **효과**: 유튜브 이탈률 최소화 (70% → 30%)
- **추천 대상**: 유튜브 업로드 최적화

#### ⚖️ 밸런스 배치
- **설명**: 강약 조절로 지루함 방지 (강-중-강-중 패턴)
- **효과**: 전체 앨범 청취 유도
- **추천 대상**: 전체 앨범 경험 중시

#### 📈 에너지 상승 배치
- **설명**: 점진적으로 흥을 돋우는 구성
- **효과**: 클라이맥스 형성
- **추천 대상**: 콘서트 셋리스트

## 🚀 사용 방법

### 1. 음악 생성
```
1. Workflow 페이지 접속
2. 스타일 입력 (예: "Upbeat indie pop, 80bpm, female vocals")
3. 곡 수 선택 (5곡 이상 권장)
4. "생성" 버튼 클릭
```

### 2. AI 순위 분석
```
1. 음악이 생성되면 "🤖 AI 자동 순서 추천" 버튼 표시
2. 버튼 클릭 → AI 분석 시작 (약 2초/곡)
3. 분석 완료 후 결과 UI 표시
```

### 3. 전략 선택
```
1. 3가지 전략 탭 비교
   - 🎣 후킹 우선 (유튜브 최적화)
   - ⚖️ 밸런스 (앨범 경험)
   - 📈 에너지 상승 (클라이맥스)

2. 각 전략별 트랙 순서 및 점수 확인

3. "✅ 이 순서 적용하기" 클릭
```

### 4. 앨범 생성
```
1. 적용된 순서로 트랙 번호 자동 설정
2. "🎬 앨범 생성" 버튼 클릭
3. ZIP + 앨범정보 다운로드
```

## 🐛 문제 해결

### Q1: "AI 분석 중 오류가 발생했습니다"
**원인**: Gemini API 키 미설정 또는 네트워크 오류  
**해결**: 
```bash
# .env 파일 확인
GEMINI_API_KEY=AIzaSyCS3nl6jke...

# 서버 재시작
pm2 restart suno-server
```

### Q2: 분석 버튼이 표시되지 않음
**원인**: 음악이 2곡 미만  
**해결**: 최소 2곡 이상 생성 후 버튼 표시

### Q3: 분석이 너무 오래 걸림
**원인**: 곡 수가 너무 많음 (30곡 이상)  
**해결**: 
```javascript
// options.maxTracks 조정
{
  "options": {
    "maxTracks": 15  // 15곡으로 제한
  }
}
```

### Q4: 비용이 예상보다 높음
**원인**: 배치 크기가 작아서 API 호출 횟수 증가  
**해결**:
```javascript
// options.batchSize 증가
{
  "options": {
    "batchSize": 10  // 5 → 10으로 증가
  }
}
```
