# 🎵 트랙 순서 선택 시스템 구현 완료

## 📋 요약
사용자가 곡의 앨범 수록 순서를 자유롭게 지정할 수 있는 시스템을 구현했습니다.

## ✨ 주요 기능

### 1️⃣ 트랙 순서 선택 UI
- **위치**: 각 곡 제목 바로 아래
- **형태**: `[1] [2] [3] ... [20]` 작은 번호 박스 (28×28px)
- **스타일**: 
  - 기본: 어두운 배경 + 오렌지 테두리
  - 선택 시: 오렌지→핑크 그라데이션 + 발광 효과 + 크기 증가
  - 호버 시: 밝은 배경 + 굵은 테두리

### 2️⃣ 사용 시나리오
```
1. 곡 생성 → 15곡 완성
2. 3번째 곡이 가장 좋음 → [1] 클릭 → 앨범 첫 곡으로 설정
3. 7번째 곡도 좋음 → [2] 클릭 → 앨범 두 번째 곡으로 설정
4. 별로인 곡 → [20] 클릭 → 앨범 마지막 곡으로 설정
5. 다운로드 시 → `01_최고의곡.mp3`, `02_좋은곡.mp3`, `20_별로인곡.mp3`
6. Time Track → 선택한 순서대로 시간 계산
```

### 3️⃣ 다운로드 파일명 반영
```
선택 전:
- 음악_1.mp3
- 음악_2.mp3
- 음악_3.mp3

선택 후:
- 01_최고의곡.mp3  (원래 3번 → 1번으로 이동)
- 02_좋은곡.mp3    (원래 7번 → 2번으로 이동)
- 03_그냥곡.mp3    (원래 1번 → 3번으로 이동)
...
- 20_별로인곡.mp3  (원래 10번 → 20번으로 이동)
```

### 4️⃣ Time Track 자동 계산
```
선택한 순서대로 시간 누적:

00:00 - 01_최고의곡
03:45 - 02_좋은곡
07:20 - 03_그냥곡
10:55 - 04_네번째곡
...
58:30 - 20_별로인곡

총 재생시간: 62:15
```

## 🔧 기술 구현

### 전역 변수
```javascript
let trackOrder = new Map(); // songIndex → trackNumber (1~20)
```

### 핵심 함수

#### `selectTrackOrder(songIndex, trackNumber)`
- 곡의 트랙 번호 지정
- 중복 방지 (같은 번호 다른 곡에 있으면 해제)
- UI 업데이트 (버튼 스타일 변경)
- Time Track 자동 재계산

#### `updateTimeTrackDisplay()`
- 트랙 순서대로 정렬
- 시간 누적 계산
- Time Track 섹션 업데이트

#### `formatTimestamp(seconds)`
- 초 → MM:SS 변환
- 예: 225초 → "03:45"

#### `createAlbumWithOrder()`
- 트랙 순서를 파일명에 반영
- 정렬 후 ZIP 생성
- 예: `01_곡제목.mp3`, `02_곡제목.mp3`

### UI 개선
- 스타일 태그: 첫 번째 태그만 표시 (0.75em, 짧게)
- 번호 박스: 미니 사이즈 (28×28px)
- 선택 효과: 그라데이션 + 발광 + 크기 변화

## 📊 데이터 흐름

1. **선택**: `selectTrackOrder(3, 1)` → 3번 곡을 1번 트랙으로
2. **저장**: `trackOrder.set(3, 1)`
3. **정렬**: `songs.sort((a, b) => a.trackNumber - b.trackNumber)`
4. **파일명**: `01_${song.title}.mp3`
5. **Time Track**: `00:00 - 01_${song.title}`
