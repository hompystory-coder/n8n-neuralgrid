## 💻 사용 방법

### Node.js에서 사용
```javascript
const playlists = require('./server/config/jjimplayPlaylists');

// 특정 플레이리스트 조회
const dawn = playlists.getPlaylistByCategory('새벽감성');
console.log(dawn.enhancedTitle); 
// "고요 속 울림, 새벽의 속삭임"

// YouTube 형식으로 포맷
const youtubeData = playlists.formatForYouTube(1);
console.log(youtubeData.title);
console.log(youtubeData.description);
```

### JSON Export
```javascript
const json = playlists.exportPlaylistsJSON();
// JSON 파일로 저장 가능
```

### CSV Export
```javascript
const csv = playlists.exportPlaylistsCSV();
// 엑셀에서 열기 가능
```
