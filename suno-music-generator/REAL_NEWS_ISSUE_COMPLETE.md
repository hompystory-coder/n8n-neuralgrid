### ✅ API 키 설정 방법

GenSpark에서 LLM API 키를 설정하면 **AI 웹 검색**이 활성화됩니다:

1. **GenSpark 프로젝트 → API Keys 탭**
2. **"Generate API Key" 클릭**
3. **"Inject" 버튼 클릭** (샌드박스 환경에 자동 주입)

설정 후:
- ✅ `~/.genspark_llm.yaml`에 실제 API 키 저장됨
- ✅ AI 웹 검색으로 **실시간 뉴스** 수집 가능
- ✅ 더 정확하고 최신 이슈 반영
