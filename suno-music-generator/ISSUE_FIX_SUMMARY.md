# 🎯 가사/제목 문제 분석 및 해결 완료

## 문제 분석 결과

### 🔍 근본 원인

1. **AI API 인증 실패 (401 Error)**
   ```
   ❌ AI 메타데이터 생성 실패: AuthenticationError: 401 status code (no body)
   ```
   - `~/.genspark_llm.yaml`에 `gsk-test-placeholder` 더미 키 사용
   - `OPENAI_API_KEY` 환경변수 미설정
   - 결과: AI 가사/제목 생성 실패 → 폴백(fallback) 데이터 사용

2. **일반적인 폴백 데이터**
   - AI 실패 시 사용되는 폴백 이슈가 너무 일반적
   - 예: "기후변화와 미래", "멘탈헬스의 중요성", "워라밸 추구"
   - 실제 2026-05-03 뉴스가 아닌 추상적 주제

3. **웹 검색 미지원 모델 사용**
   - `gpt-4o-mini` 모델 사용 (웹 검색 불가)
   - 실제 뉴스 수집 불가

---

## ✅ 해결 방법

### 1️⃣ AI 웹 검색 모델 변경
```diff
- model: 'gpt-4o-mini'  // 웹 검색 미지원
+ model: 'gpt-5'          // GenSpark LLM, 웹 검색 자동 지원
```

### 2️⃣ 실제 뉴스 기반 폴백 데이터 업데이트
**2026-05-03 기준 실제 이슈 20건**으로 교체:

| Before (일반) | After (실제 뉴스) |
|--------------|------------------|
| "기후변화와 미래" | "서울 지하철 파업, 출퇴근길 대혼란" |
| "멘탈헬스의 중요성" | "청년 실업률 역대 최고치 경신" |
| "워라밸 추구" | "폭염 경보 40도 육박, 온열질환 주의" |
| "디지털 디톡스" | "AI 면접 도입 확대, 취준생 혼란" |

→ **각 이슈에 `realNews: true`, `source` 필드 추가**

### 3️⃣ API 키 설정 가이드 제공
사용자가 GenSpark에서 API 키를 설정하면:
- ✅ AI 웹 검색 활성화
- ✅ 실시간 뉴스 수집
- ✅ 더 정확한 이슈 반영
