## 🎨 구현된 기능

### 1️⃣ ✏️ 편집 기능

#### 기능 설명
- 제목, 한글 가사, 영어 가사를 **모달 팝업**에서 편집
- 실시간 저장 및 화면 자동 새로고침
- **Glassmorphism** 스타일의 고급 UI

#### 작동 방식
```
1. "✏️ 편집" 버튼 클릭
   ↓
2. 모달 팝업 표시

   - 🇰🇷 한글 가사 (왼쪽)

   ↓
3. 내용 수정
   ↓
4. "💾 저장" 버튼 클릭
   ↓
5. 가사 목록 자동 새로고침
   ↓
6. "✅ 가사가 저장되었습니다!" 알림
```

### 3️⃣ ✅ 선택 기능

#### 기능 설명
- 선택된 가사에 **보라색 테두리** 표시
- **"✅ 선택됨"** 배지 추가
- 선택 후 버튼 비활성화
- **다음 단계** 버튼 활성화 제어

#### 작동 방식
```
1. "✅ 선택" 버튼 클릭
   ↓
2. 선택된 가사 표시
   - 보라색 테두리 (2px solid #a855f7)

   ↓
3. 선택 버튼 비활성화
   버튼 텍스트: "✅ 선택" → "✅ 선택됨"
```

## 💻 코드 구조

### 1. 편집 기능 (`editLyrics`)
```javascript
function editLyrics(index) {
  // 1. 모달 생성
  const modal = document.createElement('div');
  
  // 2. 편집 폼 표시 (제목, 한글, 영어)
  modal.innerHTML = `
    <input id="editTitle" value="${item.title}">
    <textarea id="editLyricsKo">${item.lyricsKo}</textarea>
    <textarea id="editLyricsEn">${item.lyricsEn}</textarea>
  `;
  
  // 3. 저장 버튼
  <button onclick="saveEditedLyrics(${index})">저장</button>
}
```

### 2. 저장 기능 (`saveEditedLyrics`)
```javascript
function saveEditedLyrics(index) {
  // 1. 입력값 가져오기
  const title = document.getElementById('editTitle').value;
  const lyricsKo = document.getElementById('editLyricsKo').value;
  const lyricsEn = document.getElementById('editLyricsEn').value;
  
  // 2. 업데이트
  generatedLyrics[index].title = title;
  generatedLyrics[index].lyricsKo = lyricsKo;
  generatedLyrics[index].lyricsEn = lyricsEn;
  
  // 3. 모달 닫기
  modal.remove();
  
  // 4. 화면 새로고침
  displayGeneratedLyrics();
  
  // 5. 알림
  showNotification('✅ 가사가 저장되었습니다!', 'success');
}
```

### 3. 삭제 기능 (`deleteLyrics`)
```javascript
function deleteLyrics(index) {
  const item = generatedLyrics[index];
  
  // 1. 확인
  if (confirm(`"${item.title}"\n\n이 가사를 삭제하시겠습니까?`)) {
    // 2. 배열에서 제거
    generatedLyrics.splice(index, 1);
    
    // 3. 화면 새로고침
    displayGeneratedLyrics();
    
    // 4. 알림
    showNotification('🗑️ 가사가 삭제되었습니다!', 'info');
  }
}
```

### 4. 선택 기능 (`selectLyrics`)
```javascript
let selectedLyricsIndex = null;

function selectLyrics(index) {
  // 1. 선택 저장
  selectedLyricsIndex = index;
  
  // 2. 화면 새로고침
  displayGeneratedLyrics();
  
  // 3. 시각적 표시 (displayGeneratedLyrics에서 처리)
  if (selectedLyricsIndex === index) {
    lyricsDiv.style.border = '2px solid #a855f7';
    lyricsDiv.style.background = 'rgba(168, 85, 247, 0.1)';
  }
  
  // 4. 알림
  showNotification('✅ 선택됨!', 'success');
}
```

### 5. 알림 시스템 (`showNotification`)
```javascript
function showNotification(message, type = 'info') {
  const colors = {
    success: '#22c55e',
    error: '#ef4444',
    info: '#3b82f6',
    warning: '#f59e0b'
  };
  
  // 1. 알림 생성
  const notification = document.createElement('div');
  notification.style.background = colors[type];
  notification.textContent = message;
  
  // 2. 추가
  document.body.appendChild(notification);
  
  // 3. 3초 후 제거
  setTimeout(() => notification.remove(), 3000);
}
```
