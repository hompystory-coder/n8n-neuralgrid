```

```
**원인**: 폴백 가사가 일반적인 템플릿, `${issue.title}` 단순 삽입

#### 3️⃣ **근본 원인: AI 인증 실패**
```
❌ GenSpark LLM 제목 생성 오류: 401 status code (no body)

```
- API 키 미설정으로 AI 가사/제목 생성 실패
- 폴백(fallback) 로직이 이슈를 제대로 반영하지 못함

### 1️⃣ 이슈 기반 제목 생성 함수 추가

**`generateIssueFallbackTitle()` 함수 신규 작성**

```javascript
function generateIssueFallbackTitle(issue, language, index = 0) {
  // 이슈 키워드 기반 18가지 시적 패턴
  const patterns = [
    (k) => `${k[0]}의 순간`,      // "지하철의 순간"
    (k) => `${k[0]} 너머`,         // "파업 너머"
    (k) => `멈춘 ${k[0]}`,         // "멈춘 지하철"
    (k) => `${k[1]}이 흐르다`,     // "교통이 흐르다"
    (k) => `${k[0]} 속에서`,       // "파업 속에서"
    (k) => `흩어진 ${k[0]}`,       // "흩어진 청년"
    (k) => `${k[0]}의 온도`,       // "폭염의 온도"
    (k) => `${k[0]}과 ${k[1]}`,    // "실업과 청년"
    // ... 총 18가지
  ];
  
  return pattern(issue.keywords);
}
```
