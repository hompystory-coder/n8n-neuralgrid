## 🎯 핵심 콘셉트

### 채널 아이덴티티
- **채널명 아이디어**: "RHYTHM BUDDIES" / "MELODY FRIENDS" / "BEAT PALS"
- **콘셉트**: 음악을 사랑하는 친구들이 일상 속에서 다양한 활동을 하는 모습
- **차별화 포인트**: 
  - GROOVE는 곰/강아지 → 우리는 **다양한 동물 친구들**
  - GROOVE는 오렌지 계열 → 우리는 **음악 장르별 색상**
  - 일관된 캐릭터지만 수백 가지 시나리오 가능

## 🐾 캐릭터 디자인

### 메인 캐릭터 3종 (트리오 콘셉트)

#### 1️⃣ **"비트" (Beat)** - 고양이 캐릭터
- **외형**:
  - 둥근 얼굴의 귀여운 주황색 고양이
  - 항상 헤드폰을 착용
  - 크고 반짝이는 눈
  - 작은 삼각형 귀
- **성격**: 활발하고 에너제틱, 댄스/파티 음악 담당
- **대표 색상**: 주황색 (#FF6B35)
- **활동 예시**: 
  - 춤추기, 운동, 파티, 드라이브
  - 업비트 음악 (EDM, Pop, Dance)

#### 2️⃣ **"멜로" (Melo)** - 토끼 캐릭터
- **외형**:
  - 긴 귀의 부드러운 파란색 토끼
  - 항상 작은 노트북이나 책과 함께
  - 차분한 표정
  - 둥근 안경 착용 (선택적)
- **성격**: 차분하고 집중력 있는, 공부/작업 음악 담당
- **대표 색상**: 하늘색 (#4ECDC4)
- **활동 예시**:
  - 공부, 독서, 작업, 명상
  - 차분한 음악 (Lo-fi, Study, Chill)

#### 3️⃣ **"리듬" (Rhythm)** - 강아지 캐릭터
- **외형**:
  - 플로피한 귀의 따뜻한 베이지색 강아지
  - 항상 미소 짓는 표정
  - 커피잔이나 쿠션과 자주 함께
  - 부드러운 곡선의 디자인
- **성격**: 따뜻하고 편안한, 힐링/감성 음악 담당
- **대표 색상**: 베이지/크림색 (#F4A261)
- **활동 예시**:
  - 카페, 휴식, 수면, 요가
  - 힐링 음악 (Acoustic, Jazz, Ambient)

### 서브 캐릭터 2종 (선택적 등장)

#### 4️⃣ **"베이스" (Bass)** - 곰 캐릭터
- **외형**: 크고 든든한 갈색 곰
- **성격**: 묵직하고 파워풀한
- **대표 색상**: 다크 브라운 (#2A1810)
- **음악**: Rock, Hip-hop, Bass-heavy tracks

#### 5️⃣ **"하모" (Harmo)** - 새 캐릭터
- **외형**: 작고 귀여운 노란색 새
- **성격**: 경쾌하고 자유로운
- **대표 색상**: 밝은 노랑 (#FFD93D)
- **음악**: Indie, Folk, Uplifting tracks

## 📐 썸네일 템플릿 구조

### 기본 레이아웃 (1280x720px, 16:9)

```
┌─────────────────────────────────────────┐
│  [배경: 시나리오 배경 (60%)]             │
│                                         │
│     [캐릭터: 중앙 또는 좌측 (40%)]       │
│                                         │
│  ┌───────────────────────────────────┐  │
│  │  [텍스트 영역]                     │  │
│  │  제목: 24-32pt 볼드               │  │
│  │  서브: 16-20pt 레귤러             │  │
│  └───────────────────────────────────┘  │
│                                         │
│  [장르 아이콘]     [재생시간/트랙수]     │
└─────────────────────────────────────────┘
```

### 템플릿 변형 5가지

#### Type A: 센터 캐릭터 (Center Character)
- 캐릭터가 화면 중앙에 크게
- 양쪽에 텍스트/정보
- 활동적인 장면에 적합

#### Type B: 좌측 캐릭터 (Left Character)
- 캐릭터 좌측 40%
- 우측 60%에 배경 시나리오
- 스토리텔링에 적합

#### Type C: 환경 중심 (Environment Focus)
- 배경 장면이 70%
- 캐릭터는 작게 배치 (귀퉁이)
- 분위기 강조

#### Type D: 멀티 캐릭터 (Multi Character)
- 2-3개 캐릭터 함께
- 사회적 활동 표현
- 파티/친구 테마

#### Type E: 미니멀 (Minimal)
- 단순한 배경 (80%)
- 캐릭터 실루엣 또는 작게
- 텍스트 중심

## 💻 구현 계획

### Phase 1: 캐릭터 에셋 생성 (1주차)
1. **기본 캐릭터 디자인** (5개 캐릭터)
   - 각 캐릭터의 기본 포즈 10개
   - 감정 표현 5가지 (행복, 집중, 편안, 신남, 평화)
   - 총 50개 기본 에셋

2. **의상/악세서리 세트** (10개 세트)
   - 헤드폰 3종 (오버이어, 인이어, 무선)
   - 의상 5종 (캐주얼, 파자마, 운동복, 정장, 후드)
   - 소품 10종 (커피, 책, 노트북, 기타, 요가매트 등)

### Phase 2: 배경 에셋 생성 (1주차)
1. **장소 배경** (20개)
   - 실내: 침실, 서재, 카페, 사무실, 거실
   - 실외: 공원, 해변, 도시, 산, 들판
   - 특수: 차 안, 기차, 비행기, 무대, 스튜디오

2. **시간/날씨 변형** (각 배경마다 4가지)
   - 아침/낮/저녁/밤
   - 맑음/흐림/비/눈
   - 총 80개 배경 변형

- **캐릭터**: 5개
- **활동**: 50개 (카테고리별 평균 5개 × 10 카테고리)
- **배경**: 20개
- **시간대**: 4개
- **색상 테마**: 5개

**총 조합 = 5 × 50 × 20 × 4 × 5 = 100,000개 이상**

실제로는 의미 있는 조합만 선택하여 **500-1,000개 고유 썸네일** 생성 가능
