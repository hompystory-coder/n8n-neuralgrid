#### **관리자 모드에서 가능한 설정**

##### 1️⃣ **시스템 프롬프트 (AI 지시사항)**
```
당신은 전문 작사가입니다. 사용자의 요청에 따라 
감성적이고 완성도 높은 가사를 작성하세요.

**가사 작성 규칙:**
1. 먼저 가사를 작성하고, 그 가사의 핵심 주제와 
   분위기를 반영한 제목을 추천하세요
2. 가사 구조: [Verse 1], [Chorus], [Verse 2], 
   [Chorus], [Bridge], [Chorus], [Outro]
3. 각 Verse는 4줄, Chorus는 4줄로 구성
4. 운율과 리듬을 고려하여 자연스럽게 작성
5. 반복되는 Chorus는 기억하기 쉽고 강렬하게

**제목 생성 규칙:**
1. 가사의 핵심 메시지를 3-5단어로 압축
2. 감성적이면서도 검색에 유리한 키워드 포함
3. 너무 길지 않게 (최대 50자)
4. 제목은 가사 작성 후 마지막에 추천
```

- **자유롭게 수정 가능!**
- AI가 가사와 제목을 생성할 때 이 프롬프트를 따릅니다

##### 2️⃣ **프롬프트 프리셋 (6가지)**
원클릭으로 장르별 최적화된 프롬프트 로드:
- 😢 **감성 발라드**: 깊은 감정, 서정적 운율
- ⚡ **에너제틱 팝**: 밝고 중독성 있는 훅
- 🎤 **힙합 랩**: 플로우와 펀치라인
- 🎹 **R&B 소울**: 섬세하고 감각적인 표현
- 🎸 **록 발라드**: 강렬한 감정과 다이나믹
- 💜 **K-POP**: 한영 믹스, 킬링파트, 댄스 브레이크

##### 3️⃣ **제목 생성 전략 (5가지)**
- **키워드 기반**: SEO 최적화 (예: "Love Music", "Ballad Hits 2026")
- **감성적 표현** ⭐ (기본): 예술적 (예: "그대라는 이유", "혼자인 밤")
- **은유적 표현**: 문학적 (예: "별이 된 사랑", "시간이 멈춘 곳")
- **직설적 표현**: 명확함 (예: "About Love", "이별 Story")
- **트렌드 키워드**: 유행어 포함 (예: "LOVE VIBE", "MOOD: 그리움")

##### 4️⃣ **제목 개수 설정**
- 1~10개 선택 가능
- 기본값: 3개
- 가사마다 여러 제목 후보를 AI가 추천

## 🎵 **워크플로우: 가사 먼저 → 제목 자동 생성**

### **새로운 생성 프로세스**

```
1. 사용자 입력
   ↓
   "실연의 아픔을 담은 발라드"
   
2. AI가 가사 먼저 작성
   ↓
   [Verse 1]
   In the silence of the evening glow
   I hear your voice from long ago...
   
   [Chorus]
   Forever in my heart you'll stay
   No matter how far away...
   
3. AI가 가사 분석
   ↓
   핵심 주제: "이별 후 그리움"
   감정: "슬픔", "외로움"
   
4. 제목 자동 생성 (전략 적용)
   ↓
   ⭐ 추천 제목 1: "아픔의 순간"
   ◯ 추천 제목 2: "그대라는 사랑"
   ◯ 추천 제목 3: "혼자인 밤"
```

## 💪 **왜 이 방식이 더 좋은가?**

### ✅ **가사 먼저 → 제목 생성**
1. **자연스러움**: 가사의 내용을 보고 제목을 짓는 것이 현실적
2. **정확성**: 제목이 가사의 실제 내용을 반영
3. **다양성**: 여러 제목 후보 중 선택 가능
4. **SEO**: 전략에 따라 검색 최적화된 제목

### ✅ **관리자 프롬프트**
1. **유연성**: 장르/스타일별 맞춤 설정
2. **제어력**: AI 출력을 세밀하게 조정
3. **일관성**: 프리셋으로 빠른 전환
4. **보안**: 일반 사용자에게는 숨김
